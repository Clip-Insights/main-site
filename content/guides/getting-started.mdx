You need desktop Chrome and a YouTube watch page. The extension adds a study panel beside the video. A phone browser or the YouTube mobile app is not the same environment.

## Install and open

1. Open the [Clip Insights Chrome Web Store listing](https://chromewebstore.google.com/detail/ccgechmifoecebnimnccgahnoklklilj) and select **Add to Chrome**.
2. Open or reload a YouTube video after installation. Look for the Clip Insights panel beside the player.
3. If the panel is missing, check that the extension is enabled and allowed to run on YouTube. See [troubleshooting](/guides/troubleshooting) before reinstalling: reinstalling can remove local notes.

## Make one useful note

Watch until you reach an idea you want to keep. Pause if you need time to think, then write a short explanation in the note composer and save it. The note is associated with that point in the video.

For example, instead of “important concept,” write: “The example fails because the function changes the original array. Try making a copy first.” The note should tell your future self what you understood and what to do next.

## Capture a frame

Select **Snapshot** when the player shows a useful diagram, slide or code sample. The capture uses the current video frame, not a full-page screenshot. Add a separate note to explain the part you want to remember. Select a timestamp in your timeline to return to that moment.

## Export before you leave

Select **Download** to generate a PDF from your saved material. Open it and check that the notes and images you need are present. Store the PDF somewhere you can find again.

Your timeline lives in this browser. A local download is a separate copy; it does not create a cloud backup. Signed-in users can select **Upload** to save an exported PDF to their account and manage it in the [web app](https://app.clipinsights.org).

## Add AI when it helps

Sign in using the panel's **Login** button to access account-based features. **Summary**, **Key Points** and **Chat** use the available video transcript and your plan's quotas. Start with one specific question rather than asking AI to replace the whole lesson.

If sign-in or AI is unavailable, local notes, screenshots and PDF downloads can still be useful. See [AI and transcripts](/guides/ai-and-transcripts) for prerequisites and limitations.

## Finish with a question

Before closing the video, add one question you still cannot answer. Your next session then has a clear starting point. Keep a PDF backup before clearing browser data, removing the extension or switching browser profiles.
