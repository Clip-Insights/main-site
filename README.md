# Clip Insights public site

The marketing and editorial website for https://clipinsights.org, built on the existing Next.js App Router / Velite migration. The authenticated web app remains at https://app.clipinsights.org.

## Run locally

Use Node 22.16+ and npm:

    npm ci
    npm run dev

## Verify

    npm test
    npm run lint
    npm run build
    npm run preview

In another terminal:

    node scripts/check-links.mjs http://localhost:3001

## Content and assets

- `app/page.tsx`: product homepage.
- `components/product-demo.tsx`: interactive, explicitly illustrative product walkthrough.
- `content/posts`: eleven finished articles, including five refreshed WordPress imports with preserved slugs and dates.
- `content/guides`: four product guides.
- `content/pages`: about, contact, access/plans, privacy and terms.
- `public/sample-notes.pdf`: original sample document generated by the extension's PDF renderer.
- `lib/site.ts`: domain, app/store URLs and confirmed contact address.
- `redirects.json`: preserved WordPress paths and policy aliases.

Velite builds typed content during `next dev` and `next build`. Imported article publication dates remain intact; substantive revisions have an updated date. Fonts are self-hosted, with the Inter license included.

## Deployment

See [DEPLOYMENT.md](./DEPLOYMENT.md) for Vercel, Namecheap and store-link steps. This site needs no backend environment variables, database or API keys. Cloud Run availability affects the actual account/AI tools, not public pages.

## Previous WordPress migration

The original importer remains in `scripts/migrate-wp-to-mdx.mjs` for historical use. Do not run it as part of deployment: it fetches the old site and can overwrite the reviewed content and redirect map. The retained migration utilities and tests remain part of the repository.
