# Next.js Content Site Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a validated Next.js and Velite scaffold in the existing non-empty `main-site` directory.

**Architecture:** Generate the framework-owned files with create-next-app in a temporary sibling directory and copy them into `main-site` while preserving the supplied migration inputs. Velite remains the content data layer, runs as part of Next.js development/build startup, and exposes generated collections through the `#site/content` TypeScript alias.

**Tech Stack:** Next.js App Router, React, TypeScript, Tailwind CSS, ESLint, Velite, npm.

### Task 2: Install and integrate Velite

**Files:**
- Modify: `package.json`
- Modify: `next.config.ts`
- Modify: `tsconfig.json`

- [ ] **Step 1: Install migration and content dependencies**

Run:

```bash
npm install --save-dev velite turndown turndown-plugin-gfm slugify gray-matter
```

Expected: all five packages appear in `devDependencies`.

- [ ] **Step 2: Wire Velite into Next.js**

Replace `next.config.ts` with:

```ts
import type { NextConfig } from "next";

const isDev = process.argv.includes("dev");
const isBuild = process.argv.includes("build");

if (!process.env.VELITE_STARTED && (isDev || isBuild)) {
  process.env.VELITE_STARTED = "1";
  const { build } = await import("velite");
  await build({ watch: isDev, clean: !isDev });
}

const nextConfig: NextConfig = {};

export default nextConfig;
```

- [ ] **Step 3: Add the generated-content alias**

Add this mapping under `compilerOptions.paths` in `tsconfig.json`:

```json
"#site/content": ["./.velite"]
```

- [ ] **Step 4: Check configuration types**

Run: `npx tsc --noEmit`

Expected: no TypeScript errors.
